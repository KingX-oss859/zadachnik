# Задачник — решения задач по физике (PWA)

Приложение-справочник для iPhone: поиск по номеру задачи → условие, «Дано» с переводом в СИ, чертёж, формулы, решение по шагам, ответ.
Задачник: А. Г. Чертов, А. А. Воробьёв «Задачник по физике».

## Как открыть
Выложить содержимое папки в GitHub-репозиторий → Settings → Pages → Deploy from branch `main` / root.
Ссылка вида `https://<логин>.github.io/<репозиторий>/` открывается в Safari; «Поделиться → На экран Домой» — и это приложение с иконкой, работает без интернета.
Прямая ссылка на задачу: `…/#3.12`.

## Как добавить задачу
1. `data/tasks.js` — скопировать любой объект задачи и поменять поля (формулы в `$…$`, LaTeX).
2. Если нужен чертёж — функция в `data/figures.js`.
3. В `sw.js` поднять `VERSION` (v1 → v2), чтобы телефоны обновили кэш.
